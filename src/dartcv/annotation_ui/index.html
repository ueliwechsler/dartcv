Wheel to zoom. Space + drag (or middle button) to pan. Draw by clicking vertices; Enter closes. In edit mode drag a selected polygon's vertices. Right-click a vertex to remove it; double-click an edge to add one.

Tip means the physical point, not an image-edge crossing. Exact = a visible clicked point; hidden/unknown = no guess. Board contact is separate.

Trace only visible pixels in part polygons. Use separate polygons for disconnected pieces of one dart. Inferred silhouettes never count as segmentation truth. All other pixels on a completed photo are background except ignore regions.

Originals stay untouched; all coordinates are in original-resolution OpenCV-decoded photo pixels. No images leave this machine.
